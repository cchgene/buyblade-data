# Buyblade data

Buyblade x 戰鬥陀螺價格比較網站的公開資料來源。

目前內容是網站開發用的示範資料；正式爬蟲資料上線後，由爬蟲覆寫 `data/latest.csv`，並把價格或庫存變動事件追加至分月歷史檔。

## 檔案

- `data-sources.json`：網站可讀取的資料來源清單。
- `data/latest.csv`：目前商品快照。
- `data/history-YYYY-MM.csv`：價格與庫存變動事件。

## 資料規則

- `canonical_product_id` 必須在不同賣場與不同更新批次中保持穩定。
- 日期使用 ISO 8601，建議統一採 UTC。
- 正式資料推送前應先驗證欄位、價格、日期與網址格式。
- 公開資料僅供行情參考；實際價格、庫存與交易條件以賣場頁面為準。

本資料庫目前未授予額外的再利用授權。
